## [0.1.0] - 2026-05-01

### Added
- `list_library.py` — list every product in your Gumroad library, sorted by content staleness, with optional Markdown / JSON output.
- `download_product.py` — download every file in one or more products by permalink or name match, at original quality (not transcoded HLS).
- `build_dossier.py` — generate a single Markdown research dossier with descriptions and file-level tables of contents for every product.
- `gumroad_library_tools/api.py` — shared module: container discovery, token reading, API calls.
- README, MIT license.
